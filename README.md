# Field-to-Office Project Dashboard 🏗️

A lightweight, browser-based construction project management dashboard designed to streamline field data entry into professional documentation. This tool allows field engineers and project managers to draft, log, and track Requests for Information (RFIs) without needing a heavy backend infrastructure.

## 🚀 Features

* **Instant RFI Generation:** Clean, intuitive form for inputting field issues, locations, and proposed solutions.
* **Persistent Local Storage:** Uses browser `localStorage` to save RFI logs. Data remains intact even if the page is refreshed or closed.
* **Status Tracking:** Active RFI log table to track ongoing project queries.
* **Responsive Design:** Styled with a professional, construction-friendly UI (HTML/CSS) that works across different screen sizes.
* **Zero Backend Required:** 100% client-side application. No servers, databases, or API keys needed to run.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and form handling.
* **CSS3:** Custom styling for a professional "construction software" look.
* **Vanilla JavaScript:** DOM manipulation and local storage data management.

## 💻 How to Use

1. Clone or download this repository to your local machine.
2. Open the project folder.
3. Double-click the `index.html` file to open it in your default web browser.
4. Start logging RFIs! 

*Note: Because this app relies on local storage, clearing your browser data will clear your active logs.*
